GoPro Media SDK

This GoPro Media SDK Documentation is GoPro copyrighted material. © 2025-2026 GoPro, Inc. All rights reserved. Use of this documentation is subject to the GoPro SDK Documentation License


With the Media SDK, you can process GoPro `.360` spherical video files from within your own Android Kotlin application. This guide describes the development APIs and how to use them.

Requirements

RequirementMinimum
Android minSdk33
KotlinCoroutines support required (kotlinx-coroutines)
Architecturearm64-v8a, armeabi-v7a, or x86_64

Setup

Add the Media SDK to your Android project:

  1. Take the AAR file and put it into the libs/ directory of your project

  2. Add it to your app module's gradle build, e.g. build.gradle.kts:

dependencies {
    implementation(files("libs/GoProMediaSDK.aar"))
}

JNI Considerations

The Media SDK ships a Java Native Interface (JNI) library that bundles libc++_shared.so (from Android NDK 29.0.1420685). If your app also includes the C++ runtime, deduplicate the native library in Gradle to avoid packaging conflicts.

Gradle examples:

Groovy (build.gradle):

android {
  packagingOptions {
    pickFirst 'lib/**/libc++_shared.so'
  }
}
Content copied to clipboard

Kotlin DSL (build.gradle.kts):

android {
  packagingOptions {
    jniLibs {
      pickFirsts += "lib/**/libc++_shared.so"
    }
  }
}

ProGuard / R8 Support

When you're ready to package your new production application, the AAR contains consumer ProGuard rules that are merged into your app's shrinker configuration automatically. No additional rules are needed for the SDK's public API.

Using the APIs

The Media SDK API is delivered as a set of free functions with supporting enums and object classes. To use them, add the following imports to your Kotlin code:

For exporting a .360 to equirectangular media:

import com.gopro.mediasdk.exportEquirectangular
import com.gopro.mediasdk.ExportEvent
import com.gopro.mediasdk.GPCodec
import com.gopro.mediasdk.GoProExportOptions
import com.gopro.mediasdk.GPResolution
import com.gopro.mediasdk.GPStabilization
import com.gopro.mediasdk.Resolution

File Requirements

Input

  • Must be a GoPro .360 spherical video file.

  • Must exist on the local filesystem and be readable by the process (i.e. File.canRead() returns true).

  • Content URIs (content://) are not accepted — copy to a local File first if necessary.

Output

  • Must be a local filesystem path writable by the process.

  • If the output parent directory does not exist, the SDK will attempt to create it. Ensure your app has write permission to the target location.
